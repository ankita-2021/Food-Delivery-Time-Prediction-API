# 🚀 Food Delivery Time Prediction API

## 📌 Overview
This project is an end-to-end Machine Learning system that predicts food delivery time based on multiple factors like location, order time, and delivery conditions.
It covers the complete ML lifecycle — from data preprocessing to model deployment via API.
---
## ⚙️ Tech Stack
- **Programming:** Python  
- **Data Processing:** Pandas, NumPy  
- **Model:** XGBoost  
- **API Framework:** FastAPI  
- **Deployment Ready:** Uvicorn  
---
## 📊 Features
- Data cleaning and preprocessing of the raw delivery dataset  
- Feature engineering (order hour, pickup time, preparation time, etc.)  
- Trained an ML model for delivery time prediction  
- REST API for real-time predictions  
- JSON-based input/output system  
---
## 🧠 How It Works
1. Raw data is cleaned and transformed  
2. Features are engineered from timestamps and delivery info  
3. Model is trained using XGBoost  
4. Model is saved as `model.pkl`  
5. FastAPI serves predictions via `/predict` endpoint
